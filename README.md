
# Dust–Cloud Vertical Configuration Analysis

This repository contains the processed data and analysis code used in the manuscript “Dust–Cloud Vertical Configuration Influences the Effective Radius of Low-Level Warm Clouds at Contrasting Marine and Continental Sites”.

The repository includes scripts and notebooks for both ground-based ARM observations and satellite-based analyses. The ARM analysis uses processed dust, cloud, and meteorological variables from the Eastern North Atlantic and Southern Great Plains sites. The satellite analysis uses CALIPSO, CloudSat, and MODIS observations to identify dust–cloud vertical configurations for comparison with the ARM-based results.

The code supports data processing, dust–cloud collocation, vertical-configuration classification, statistical analysis, and figure generation.
